# Visual System And Product Shell

## Objective

Give the existing site a coherent product shell and visual foundation without rebuilding routes or workflow.

## In Scope

- CSS tokens for color, spacing, type scale, borders, shadows, and focus states.
- Clear public-product visual treatment versus local/admin treatment.
- Navigation polish using existing routes.
- Page header and section hierarchy.
- Consistent chips, badges, action buttons, and cards.
- Reduced admin/table feel on public pages.

## Not In Scope

- Do not change route behavior beyond label/order/de-emphasis.
- Do not remove admin pages.
- Do not redesign every card in this slice.
- Do not change scoring or data.

## Style Direction

Use:

- modern neutral base;
- semantic colors for fit, caution, missing, selected, and source-backed information;
- compact but comfortable spacing;
- clear action hierarchy;
- strong focus states;
- cards with restrained borders and elevation.

Avoid:

- heavy gradients;
- decorative blobs/orbs;
- one-hue palettes;
- oversized marketing hero layouts;
- tiny admin labels as primary navigation.

## Done Criteria

- Public pages feel visually distinct from admin/source/build pages.
- Navigation reads like applicant workflow, not data maintenance.
- Shared tokens are used by later slices.
- No text/button overflow introduced.
