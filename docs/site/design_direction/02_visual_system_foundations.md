# Visual System Foundations

## Objective

Define the first visual-system foundation to implement after node-backed cards are working.

## Foundations

- restrained neutral base;
- semantic confidence/risk colors;
- modern sans-serif typography;
- compact metric groups;
- clear card elevation/borders without heavy decoration;
- strong focus states;
- consistent chips and badges;
- mobile-first spacing and touch targets.

## Semantic Color Meanings

- Green: strong fit, low concern, complete/source-backed.
- Amber: caution, partial confidence, review needed.
- Red: hard concern, critical missing field, hard no.
- Blue: source-backed information, methodology, reference context.
- Gray: unknown, not reviewed, unavailable.
- Accent: selected/shortlisted state only.

## Guardrails

- Do not let color carry meaning alone.
- Do not create a one-hue theme.
- Do not use decorative gradients or blobs.
- Do not bury data confidence behind visual polish.

## Done Criteria

- Tokens and components can express fit, confidence, caution, missing data, and selected state consistently.
- The system reads as modern and serious.
