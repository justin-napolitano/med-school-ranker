# Transparency and Trust Patterns

## Objective

Make trust, source quality, and uncertainty visible as part of the core interface.

## Required Patterns

- source confidence chip;
- missing data chip;
- provisional/partial state;
- "why this rank" explanation;
- source link panel;
- methodology card;
- AAMC national-grid caveat;
- review-needed state;
- private/local-only state when relevant.

## Display Rules

- Put caveats near the value they qualify.
- Keep source confidence visible on cards and profiles.
- Do not hide missing data in expanded-only sections when it materially affects ranking.
- Make methodology accessible from rankings and profiles.
- Keep national aggregate context clearly separate from school-specific probability.

## Done Criteria

- Users can understand why a school ranks where it does.
- Users can tell whether a fact is source-backed, missing, or provisional.
- Transparency feels useful, not like legal fine print.
