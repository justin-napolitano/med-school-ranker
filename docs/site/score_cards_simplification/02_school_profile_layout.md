# School Profile Layout

## Goal

Make each school route feel like a profile first and a data audit second.

## Header

Include:

- school name;
- degree;
- city/state;
- source link;
- status switch;
- compare action.

## At A Glance

Show:

- Decision Rank;
- Admissions Tier;
- MCAT average;
- GPA average;
- AAMC band;
- in-state estimated cost;
- out-of-state estimated cost;
- data quality badge.

## Why It Ranks Here

Use concise bullets from score contributions.

Avoid overwhelming the first viewport with raw contribution tables.

## Review Controls

Keep visible controls limited to:

- status switch: `None / Interested / Applying`;
- compare action.

Do not add notes fields in this slice.
