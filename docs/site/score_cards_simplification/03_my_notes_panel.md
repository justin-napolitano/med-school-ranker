# Review Controls

## Goal

Keep the applicant-facing review workflow simple.

## Visible Controls

- Status: `None / Interested / Applying`
- Compare action

## Deferred

- Do not add notes fields in this slice.
- Do not add interest, fit, happiness, culture, or regret inputs in this slice.
- Hard-no fields should stay hidden from the primary workflow for now.

## Export

Score-card edit export remains available but should move to a secondary details area.
